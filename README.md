# Organizations Dataset Preprocessing Project

## 📋 Project Overview
A comprehensive data preprocessing system for cleaning and preparing Organizations Dataset for AI/ML applications.

## 🎯 Features
1. **Data Loading** - Load CSV dataset with 9 organizational fields
2. **Data Exploration** - Analyze dataset structure, industry distribution, country stats
3. **Quality Analysis** - Detect missing values, duplicates, data inconsistencies
4. **Data Cleaning** - Automated cleaning pipeline for organizational data
5. **Data Export** - Save cleaned data for further analysis

## 📊 Dataset Fields
The system processes the following 9 organizational fields:
- Index
- Organization Id
- Name
- Website
- Country
- Description
- Founded (Year)
- Industry
- Number of employees
